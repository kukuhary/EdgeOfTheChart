# 『해도의 끝 (가제, Edge of the Chart)』 마스터 기획서 인덱스

> **16세기 대체역사와 40%의 해양 전설이 교차하는 2D 레트로 대항해 RPG · 전술 시뮬레이션**  
> 원작 『대항해시대 2』의 항해·탐험·군상극의 깊이를 계승하면서, **3척 정예 함대 전술**과 **독립 해상 세력 건설**, 그리고 **Godot 4 (.NET / C#) 기반 순수 시뮬레이션 코어**로 재설계한 마스터 설계 문서 세트입니다.

---

## 1. 프로젝트 개요 (Executive Summary)

『해도의 끝』은 1522년 마젤란 선단의 귀환 직후를 배경으로, 유럽 5개국과 동방 조선에서 출발한 **6명의 주인공**이 미지의 해역을 개척하고, 해적·열강·심해 괴수·유령선에 맞서 자신만의 항해사와 독립 거점을 일구어나가는 2D 레트로 해양 RPG입니다.

원작 특유의 고독하고 긴장감 넘치는 원양 항해 감각(실시간-틱 항해, 풍향·해류, 하드코어 보급·재난, 조난 후 재기)과 항구 마을 도보 탐색의 몰입감을 충실히 계승하되, 전술 피로도를 낮추고 개성을 극대화하기 위해 **함대 최대 규모를 3척(기함 1 + 요함 2)으로 정예화**하고, **선장 일기토를 과감히 삭제**하여 **함대전·거대 괴수전·항구 공성전**의 3대 전용 전투에 화력과 설계를 집중했습니다.

## 4. 주요 설계 결정 로그 (Architecture & Design Decisions)

### ADR-01: Godot 4 (.NET / C#) + 순수 C# 시뮬레이션 코어 분리
- **결정**: 엔진은 **Godot 4 (.NET)**를 사용하고, 게임 로직 전체는 엔진에 비의존적인 순수 C# 라이브러리(`SimulationCore`)로 분리합니다.
- **이유**: 2D `TileMapLayer`와 복잡한 RPG 다중 창 UI(`Control` 노드) 구축 속도가 빠르며, 6인 교차 타임라인·항해 생존·경제 시세·독립 세력 월말 정산·JSON 세이브/로드를 `dotnet test`(xUnit)로 엔진 실행 없이 고속 검증할 수 있습니다.

### ADR-02: 함대 최대 규모 3척 제한 (기함 1 + 요함 2)
- **결정**: 원작의 대함대 편성 대신 플레이어 함대 상한을 **최대 3척**으로 고정합니다.
- **이유**: 대규모 함대는 매 턴 이동/명령 피로도가 급증하고 개별 선박과 요함 선장의 개성이 묻힙니다. 3척 정예 함대는 ① 기함과 2척의 요함에 각각 고유 역할(포격함·기동/백병함·수송/보급함)과 핵심 항해사를 배치하는 전술 밀도를 높이고, ② 거대 괴수의 예고 공격을 회피 기동하거나 해안 포대를 뚫는 턴제 템포를 경쾌하게 유지합니다.

### ADR-03: 선장 일기토 삭제 및 3대 전용 전투 집중
- **결정**: 1:1 선장 일기토 미니게임과 관련 전용 씬을 완전히 삭제합니다.
- **이유**: 일기토가 존재하면 선장 1명의 개인 검술·장비 스탯이 함대 전술과 선박 운용의 가치를 압도하는 문제가 생깁니다. 대신 선박과 선원의 총력전이 빛나는 **① 8방향 그리드 함대전(`NavalBattleScene`)**, **② 부위 파괴와 예고 회피의 거대 괴수전(`LeviathanBattleScene`)**, **③ 포대 돌파-상륙-본부 결전의 3단계 항구 공성전(`PortSiegeScene`)**에 개발 리소스를 집중합니다.

### ADR-04: 역사 60% + 전설 40%의 패시브·규칙 변형형 신비
- **결정**: 마법 액티브 스킬바를 두지 않고, **선수상·성유물·저주 유물·특수 탄약(은포탄/화전)·선원 미신**이 시뮬레이션 규칙 자체를 변형하도록 설계합니다.
- **이유**: 16세기 대항해 시대의 묵직한 현실감을 훼손하지 않으면서도, 미지의 바다에서 얻은 유물과 선원의 미신이 풍향·괴혈병·반란·유령선 내성·괴수 약점에 실질적인 전략 변수(하이리스크·하이리턴)로 작동하게 합니다.

### ADR-05: 6인 완전 독립 군상극 & 연출 중심 카메오 교차
- **결정**: 모든 주인공을 엮는 공통 흑막을 두지 않고, 같은 시대(1522~1535)를 살아가는 6개국의 독립 서사가 주요 항구·해역에서 연출 중심의 카메오 이벤트(일부 핵심 분기 포함)로 교차하도록 설계합니다.
- **이유**: 억지 합류 서사보다 각 인물 본연의 동기(형의 실종, 복수, 세계 지도, 상업 제국, 해상 독립국, 조선의 역방향 서진)를 온전히 살릴 수 있으며, 6인 분기 조합 폭발로 인한 시나리오 버그를 안정적으로 제어할 수 있습니다.
